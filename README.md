# 🌸 Hayat Django CMS Site

A fully working and responsive website built using *Python, **Django, and **Django CMS*.  
This project demonstrates backend logic, authentication using *Google Login (OAuth), and database management with **PostgreSQL*.

---

## 🚀 Features

- Google Login Authentication (OAuth)
- PostgreSQL Database Integration
- Responsive Frontend using HTML & CSS
- Deployment on *Heroku* with a custom domain
- Organized structure and CMS-based pages

---

## 🛠 Technologies Used

- Python  
- Django & Django CMS  
- PostgreSQL  
- HTML, CSS  
- Heroku Deployment  
- Git & GitHub
